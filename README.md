# Сайт Ольги - мастер по волосам 💇‍♀️🌸

Одностраничный сайт-визитка: наращивание волос, окрашивание, кератин, ботокс, афрокосы, биозавивка и косметология.

**Посмотреть:** https://glebsarabajko-boop.github.io/olga-hair-stylist/

## Технологии

Чистый HTML + CSS + немного JavaScript. Без сборки и зависимостей - клонируй и открывай `index.html`.

## Структура

- `index.html` - разметка и тексты
- `css/styles.css` - оформление (цвета вынесены в CSS-переменные в начале файла)
- `js/main.js` - мобильное меню, анимации появления, год в подвале
- `images/` - фото работ и портрет

## Как обновить

Отредактируй файлы, закоммить и запушь в `main` - GitHub Pages пересоберёт сайт автоматически в течение минуты.

## Как обновить с другого компьютера

```bash
git clone https://github.com/glebsarabajko-boop/olga-hair-stylist.git
```
